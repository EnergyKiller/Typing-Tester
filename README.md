# Typing Tester 🖥️

A simple Python-based project that allows users to test their typing speed and accuracy.

## How It Works

1. Run the Python program.
2. The program displays a sentence for the user to type.
3. Press ENTER to start typing the displayed sentence.
4. Type the sentence as quickly and accurately as possible.
5. Press ENTER after finishing to see your results.

## Results

After completing the test, the program displays:

- **Time Taken:** Total time required to type the sentence.
- **Typing Speed:** Typing speed measured in Words Per Minute (WPM).
- **Accuracy:** Percentage of correctly typed characters.

## Technologies Used

- Python

## Purpose

This project was created to practise Python programming and understand basic concepts such as user input, string handling, time calculation, and accuracy calculation.
